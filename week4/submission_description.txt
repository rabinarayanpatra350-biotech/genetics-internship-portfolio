This Week 4 report documents genePipe, a working automated pipeline for genetic data analysis that I designed, implemented, tested and ran. It addresses every objective of the task: it automates data cleaning, quality control, multiple sequence alignment, variant calling, statistical analysis and phylogenetic reconstruction, and it is documented with annotated code, flow diagrams and a verified sample run report. The pipeline is a Python package of twelve modules driven by a single validated configuration file, run from the command line, with a run manifest that records every stage's status, timing, metrics and output files. It is verified by 86 automated tests covering every module and the end-to-end path. I ran it on a seeded simulated cohort of 22 sequences, where it correctly recovered a deliberately planted marker — the variant g.612C>G, present in 10/10 cases and 0/10 controls, the only one of 141 tested sites to survive Benjamini-Hochberg false-discovery correction — and then ran the same pipeline unchanged on real public COX1 sequences from twelve vertebrates, where it reproduced the expected groupings (primates 100%, birds 100%, ray-finned fish 99.8% bootstrap support). The report includes seven annotated code listings explaining the logic, four flow diagrams, and an efficiency analysis showing a repeat run drop from 17.2 seconds to 0.0 seconds via the stage cache. It also documents honestly the eleven substantive defects I found and fixed during development, each with its symptom, root cause, fix and a regression test, because how a pipeline fails matters as much as how it succeeds.
